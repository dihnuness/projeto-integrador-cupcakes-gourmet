# Aplicação dos Conceitos de IHC e UX

O desenvolvimento das interfaces foi realizado seguindo princípios de Interação Humano Computador (IHC).

Foram adotadas as seguintes práticas:

- Interface simples e intuitiva;
- Utilização de cores suaves;
- Organização clara dos elementos;
- Facilidade de navegação;
- Redução da quantidade de cliques para realizar pedidos;
- Layout responsivo.

O objetivo é oferecer uma experiência agradável para os clientes da cafeteria.
