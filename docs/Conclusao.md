# Conclusão

O desenvolvimento do sistema Cupcakes Gourmet permitiu aplicar os conceitos estudados durante a disciplina Projeto Integrador Transdisciplinar II.

Foram utilizados conhecimentos de Engenharia de Software, modelagem UML, banco de dados relacionais, desenvolvimento front-end, desenvolvimento back-end e arquitetura MVC.

A solução proposta atende às necessidades da cafeteria, permitindo o gerenciamento de clientes, produtos, pedidos, pagamentos e entregas.

Durante o projeto foi possível compreender a importância do levantamento correto de requisitos, da organização das etapas de desenvolvimento e da realização de testes para garantir a qualidade do software.

O projeto contribuiu significativamente para o desenvolvimento das competências técnicas necessárias para atuação profissional na área de tecnologia.
