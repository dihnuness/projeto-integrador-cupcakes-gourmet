# Requisitos Não Funcionais

RNF01 - O sistema deve possuir interface amigável.

RNF02 - O sistema deve responder às solicitações em tempo adequado.

RNF03 - As informações dos usuários devem ser armazenadas com segurança.

RNF04 - O sistema deve ser compatível com navegadores modernos.

RNF05 - O banco de dados deve garantir integridade das informações.

RNF06 - O sistema deverá utilizar arquitetura MVC.
