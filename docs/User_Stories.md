# User Stories

## US01

Como cliente

Quero visualizar o cardápio de cupcakes

Para escolher os produtos desejados.

---

## US02

Como cliente

Quero realizar meu cadastro

Para efetuar pedidos.

---

## US03

Como cliente

Quero fazer login

Para acessar minha conta.

---

## US04

Como cliente

Quero montar um pedido

Para comprar cupcakes online.

---

## US05

Como administrador

Quero visualizar os pedidos

Para realizar o gerenciamento das entregas.

---

## US06

Como administrador

Quero atualizar o status da entrega

Para informar o andamento do pedido ao cliente.
